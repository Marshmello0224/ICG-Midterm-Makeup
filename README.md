# ICG Midterm Makeup

Scene Setup: The Scene is very basic due to time constraints. It has a player model, a movement function, and a small scene with a couple objects for the player to move around it. I chose a simple cylinder model to be the player model to get the point across

Reflection Shader: I built the reflection shader off of the one shown in class, except I made it with the colour green in mind as that is what I planned to use for the player model.

Lambert Shader: Built this one off the one shown in class, for some reason it works on the actual unity editor, but it turns pink in the build, as though it doesn't have a texture. It's supposed to be red.
